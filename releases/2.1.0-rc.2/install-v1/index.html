Optional bootstrap, not permission

Which chain data should you use?

Keep existing valid data, start empty and sync normally, or import this bootstrap/your own verified copy. These are data choices, separate from the three service roles.

One snapshot, thirteen download pieces

The optional 13.93 GB format-4 snapshot contains both native chain and EVM state at native order 20,821,036 / EVM block 20,374,135. It is a bootstrap—not a complete historical archive claim. Catch-up is still needed.

The HTTP helper checks 13 ordered pieces and the complete assembled SHA-256. Parts are not standalone datasets.

Know what has actually passed

Running is not yet mining.

The guide distinguishes download, staging, service startup, chain synchronization and mining acceptance. Native VM install checks do not prove physical ASIC work, block/accounting progression, reboot or soak. The original AMD64 TesterD mining receipt remains separately available.
