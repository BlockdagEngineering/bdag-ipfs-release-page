Three independent options

Run only what you need

Each role is independently installable. The full runtime ZIP supplies the dependencies; your chosen mode decides which services run. You can also run all three together.

Node-only

Keep your own chain

Run Core and its supervisor. Sync normally from peers, use this optional bootstrap, or validate your own copied dataset. No pool database or dashboard required.

Pool-only

Connect miners to your node

Run Pool with its own PostgreSQL accounting database. Supply a compatible node endpoint and your own payout configuration. Do not copy another pool's ledger or identity.

Dashboard-only

Observe your services
