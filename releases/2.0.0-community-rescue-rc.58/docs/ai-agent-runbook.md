## Reward Correction

The node supplies the coinbase reward as a `uint64` count of 1e8 atomic units.
The previous pool multiplied that value by `10^10` while it was still a
`uint64`. A normal mainnet reward exceeds the type's maximum after conversion
to Wei, so the multiplication wrapped and the pool credited only the residue.

RC58 converts to arbitrary-precision integer arithmetic before scaling and
keeps exact values through the 1% fee, PPLNS allocation, database writes,
maturity, and payout calculation.

Regression vector:

```text
atomic reward        23,983,626,033
gross reward            239.83626033 BDAG
gross Wei            239,836,260,330,000,000,000
1% pool fee                2.3983626033 BDAG
fee Wei                2,398,362,603,300,000,000
sole-account credit      237.4378977267 BDAG
credit Wei            237,437,897,726,700,000,000
old wrapped gross          28,587,371,775,828,992 Wei
```

At the demonstrated `4,259` accepted blocks/day, this exact 1% credit
corresponds to approximately `1,011,248.01 BDAG/day` per X100. Treat that as a
reconciliation vector, not a guaranteed production rate; actual results
depend on accepted block count and network conditions.

This is a pool-accounting correction, not a new subsidy. RC58 does not change
the consensus subsidy formula, block-header validation, protocol reward
distribution, pool fee, PPLNS proportions, maturity, or miner eligibility.

   architecture, and chain identity validates.

## Install And Verify

Use the command generated by the finalized release page. Select `Keep / sync`;
use absolute paths and supply only the public `0x...` payout address for a
mining profile. The installer must preserve existing accounting and chain
data.

After installation, require healthy services, chain ID `0x57c`, advancing
canonical native and EVM heads, miner readiness, and accepted blocks. For at
least one mature post-upgrade block, compare:

- raw template reward in atomic units;
- exact atomic-to-Wei conversion;
- transaction fees and gross `blocks.reward`;
- the configured 1% `blocks.fees`;
- PPLNS credits;
- liquid and staked protocol receipts.

The exact regression input above must produce gross `239.83626033 BDAG`, fee
`2.3983626033 BDAG`, and sole-account credit `237.4378977267 BDAG`. The old
wrapped value must not recur.

If any check fails, stop that host, preserve redacted evidence, and restore the
previous verified software without deleting its database or chain data.
Historical reconciliation is a separate reviewed operation.
