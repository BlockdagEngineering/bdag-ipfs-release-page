Existing node upgrade

Keep qualified chain data, peerstore, pool accounting, Stratum identity, and owner payout mappings. Stage the new software beside the live stack and cut over only after native-safe readiness. An ordinary upgrade downloads neither dataset.

Mining continuity matters. Never redirect an ASIC to an unverified payout lane. Preserve the working stack for immediate rollback and keep the final cutover to a normal restart.

Verify first

Download this small page directory, authenticate its key fingerprint, signatures and hashes, then select the local architecture.

./verify-load.sh /absolute/path/to/rc65

Empty node only

Select compact data by default, or explicitly request the larger archive restore. The installer forecasts download, extraction and reserve space before transfer.
