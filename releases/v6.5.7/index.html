Ubuntu packages

printf 'net.ipv6.conf.all.disable_ipv6 = 1\nnet.ipv6.conf.default.disable_ipv6 = 1\n' | sudo tee /etc/sysctl.d/99-bdag-disable-ipv6.conf >/dev/null && sudo sysctl -w net.ipv6.conf.all.disable_ipv6=1 net.ipv6.conf.default.disable_ipv6=1 && sudo apt-get update && sudo apt-get install -y docker.io docker-compose-v2 ca-certificates curl unzip zstd tar python3 iproute2 arp-scan nmap coreutils && sudo systemctl enable --now docker && sudo usermod -aG docker "$USER"

Linux installer

Choose what you want to run

The verified helper is downloaded by immutable IPFS CID, then it downloads the matching payload, verifies SHA256, extracts it, and runs the packaged installer. Filebase mirrors are tried when public gateways are slow. Set BDAG_SKIP_PAYLOAD_INSTALL=1 to stop after extraction.

What the installer does

1

Checks Linux CPU architecture and selects AMD64 or ARM64.

2

Downloads the matching IPFS-pinned payload and verifies SHA256.

3

Installs operator seeds plus live public service-port peers, preserves packaged peers, uses IPFS and Filebase gateway fallback for payloads, uses S3 for optional snapshot restore, disables host IPv6 for Docker Hub pulls, pre-pulls Docker base images with retry, and runs the packaged installer.

Optional Chain Data Restore

Use the S3 latest snapshot when you want a restore-first install. The helper reads SHA256 and size from the S3 object metadata, downloads the archive with resume/retry, verifies it, extracts it into data/node/mainnet, then starts the packaged installer. Use a host with at least 120 GB of disk.

rm -f install-v6.5.7.sh; curl -4 --http1.1 -fsSL --connect-timeout 20 --speed-limit 1024 --speed-time 60 "https://ipfs.filebase.io/ipfs/QmZpCSyhG8e15UqNhjaKyUGyFTrNhPsFqauSC3bBjDpXaS" -o install-v6.5.7.sh || curl -4 --http1.1 -fsSL --connect-timeout 20 --speed-limit 1024 --speed-time 60 "https://ipfs.io/ipfs/QmZpCSyhG8e15UqNhjaKyUGyFTrNhPsFqauSC3bBjDpXaS" -o install-v6.5.7.sh || curl -4 --http1.1 -fsSL --connect-timeout 20 --speed-limit 1024 --speed-time 60 "https://dweb.link/ipfs/QmZpCSyhG8e15UqNhjaKyUGyFTrNhPsFqauSC3bBjDpXaS" -o install-v6.5.7.sh; test -s install-v6.5.7.sh && chmod +x install-v6.5.7.sh && BDAG_RESTORE_SNAPSHOT=1 BDAG_DEPLOY_KIND=pool BDAG_CHAIN_MODE=non-archive ./install-v6.5.7.sh
