# BDAG IPFS Release Page

This local repo stores the IPFS release-page source, runbooks, peer lists, manifests, and publishing notes for BDAG Community pool stack releases.

Current release: `v6.3.20`.

Important files:

- `releases/v6.3.20/index.html` - self-contained public IPFS page.
- `releases/v6.3.20/release-manifest.json` - CIDs, hashes, chain-data links, and live validation summary.
- `releases/v6.3.20/docs/human-install.md` - human install runbook.
- `releases/v6.3.20/docs/ai-agent-runbook.md` - AI-agent install runbook.
- `releases/v6.3.20/peer-probe.json` - public P2P seed peer reachability evidence.

Large release zip files are intentionally ignored by Git. They are published to IPFS and referenced by CID/SHA256.
