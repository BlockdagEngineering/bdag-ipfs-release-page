# BlockDAG release page

The current community page is the HTTPS IPFS-first [2.1.0-rc.2 release](releases/2.1.0-rc.2/index.html). Its direct HTTPS mirror is a labelled fallback; native `ipfs://` links remain a separate IPFS-client path. Browser links cannot force HTTP/1.1, so use the explicit `curl --http1.1` commands or the scoped downloader for protocol-controlled retrieval and verify complete expected size and SHA-256 before execution.

The companion contains the [operator install guide](releases/2.1.0-rc.2/install-v1/INSTALL.html), [download guide](releases/2.1.0-rc.2/install-v1/DOWNLOADS.html), [publisher statement](releases/2.1.0-rc.2/install-v1/PUBLISHER.html), and prominently **NOT QUALIFIED** [RC65 migration guidance](releases/2.1.0-rc.2/install-v1/MIGRATION.html) plus its [AI runbook](releases/2.1.0-rc.2/install-v1/MIGRATION-AGENTS.html). The original RC2 records and runtime sources remain unchanged.
